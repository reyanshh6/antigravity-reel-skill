# Antigravity Reel Skill 🚀

An advanced, zero-API custom skill for Google Antigravity designed to fully automate the creation of high-retention vertical videos (Reels/Shorts). 

With a single `/reel [topic]` command, this AI agent:
- Writes a viral 60-second script based on a proven hook-retention framework.
- Generates natural Hindi voiceovers using local `edge-tts`.
- Extracts precise word-level timestamps via `faster-whisper` for Hormozi-style kinetic captions.
- Auto-fetches and removes backgrounds from public figure images using `rembg`.
- Stitches the final video using `MoviePy` with custom spring-easing, Ken Burns zoom, and auto-synced SFX.

Built for zero API costs and maximum vibe coding efficiency.
